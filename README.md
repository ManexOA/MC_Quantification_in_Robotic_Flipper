# MC_Quantification_in_Robotic_Flipper
A project focused on quantifiying the Morphological Computation (MC) in a turtle-inspired robotic flipper with sand and water locomotion.

1. Position and Load data was collected from one of the motors controlling the flipper in X axis (during sand crawling) and Z axis (during swimming), across 10 cycles for each gait.
2. Collected data was feeded into an algorithm to quantify MC, using MATLAB.
3. The MATLAB script plots the MC value across the whole cycles of crawling and swimming gaits, along with the position adn load values of the motor.
